# README figures

Scripts that draw `man/figures/inlandwaters.png`, `ladder.png` and
`scaling.png` from the real packages (wkpool, sf, silicate for the
`inlandwaters` data, meshcore for the lattice panel). Run from a
folder holding `R/` (these scripts) and `figures/`; `fig-scaling.R`
reads `bench/results/scaling.csv` (path set at the top of the script).
